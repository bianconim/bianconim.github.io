UPLOAD TO GITHUB PAGES
1. Open the bianconim.github.io repository.
2. Delete/replace the old index.html if needed.
3. Upload ALL files and the entire assets folder to the repository root.
4. Commit to main.
5. GitHub Pages will republish automatically.

IMPORTANT
Do not upload the outer matteobianconi_full_site folder itself as a folder. The repository root should contain index.html directly.

EDITING
- Text/content: edit the relevant .html page.
- Site-wide typography/spacing/colours: assets/style.css
- Abstract artwork: replace the .webp file with a new image using the same filename.

CUSTOM DOMAIN
Do not add a CNAME file until you are ready to switch matteobianconi.com from WordPress to GitHub Pages.
